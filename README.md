# Olist Customer Intelligence & Retention Lab

A real-data ecommerce customer intelligence and retention analytics platform built on the
public Olist Brazilian E-Commerce dataset (≈100k orders), using Python, customer segmentation,
cohort retention analysis, and Streamlit.

## Status

Repository initialised. The analysis pipeline, application, reports and deployment are added
in the commits that follow.

## Dataset

Brazilian E-Commerce Public Dataset by Olist — CC BY-NC-SA 4.0, via Kaggle:
<https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce>

The raw CSVs are not committed. Download instructions are added with the pipeline.
